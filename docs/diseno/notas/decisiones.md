# Decisiones de diseño: Fundación v2

Decisiones de interfaz tomadas por Dante (resumen; el detalle y las escenas están en `docs/fundacion_v2_pantallas.md`). Los ADR las citan por ID.

| ID | Decisión |
|---|---|
| D-001 | Estructura «Mesa de Risk»: el mapa a pantalla completa y todo flotando encima; jugadores a la derecha, misiones a la izquierda, ambos centrados. |
| D-002 | Fundación es el primer juego horizontal también en el celular. |
| D-003 | Barra de tiempo arriba de toda la pantalla; siempre visible (gris cuando no hay tiempo que contar) y corre también en los turnos de bots. |
| D-004 | Las tarjetas de la mano son privadas (los demás ven dorsos), salvo las ganancias de cada tirada, que se ven de frente. |
| D-005 | Tarjetas sin texto: una por unidad, con color y dibujo. |
| D-006 | La tirada: dados 3D del Diez mil en una franja oscura de lado a lado en el centro, con «Sale N» a la derecha; la sombra del dado sigue la perspectiva de la mesa. |
| D-007 | Todas las ventanas (ganancias, descarte, construir, misiones y pedidos, entrega) usan la misma banda oscura con bordes dorados. |
| D-008 | Descarte: tarjetas grandes y tocables; «Faltan N» pasa a «Descartar». |
| D-009 | Construir muestra siempre las cuatro opciones; las que no se pueden quedan apagadas con lo que falta, y tocarlas no abre nada (solo avisa). |
| D-010 | Entregas sin elección de tarjetas: solo «Atrás» y «Entregar». |
| D-011 | Colocación inicial asistida: se ven los recursos que daría cada pueblo y cuáles faltan. |
| D-012 | El bandido se mueve solo y la cruz aparece al llegar. |
| D-013 | Lo que construye cualquier jugador se muestra con zoom y una marca (anillo con aro de rayas y destellos) del color de quien construyó. |
| D-014 | Contador de piezas con el icono de cada pieza y «tienes/máximo»; el camino tiene un sprite propio. |
| D-015 | Las carreras (camino más largo y ejército) se ven en la lista de misiones con su dueño («Reclamado por …»); las filas de los jugadores no llevan logos. |
| D-016 | Final de partida, ayuda y sala de espera como en los otros juegos (la ayuda en láminas con poco texto). |

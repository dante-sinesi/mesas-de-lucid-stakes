# RF-001: El servidor decide todo

## Descripción

El servidor es autoritativo: el cliente solo envía acciones (descartar, construir, colocar, entregar, pasar, seguir y atrás) y el servidor las valida.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Un cliente envía «construir» fuera de su turno | el servidor responde «No es tu turno» y el estado no cambia |

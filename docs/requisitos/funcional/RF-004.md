# RF-004: La tirada y la cobranza las hace el servidor

## Descripción

El servidor hace la tirada y la cobranza al empezar el turno, de forma determinista con el azar de la mesa.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Mismo azar y misma partida | misma tirada y mismas ganancias |

# RU-018: Zoom del mapa con gestos y rueda

## Descripción

El mapa se acerca y se aleja con dos dedos (pellizco) en el celular y con la rueda del mouse en escritorio, y se mueve arrastrando. Un toque corto sigue eligiendo. Al elegir dónde construir en el celular se ve primero todo el mapa con puntos; el primer toque elige la zona (la cámara se acerca) y el segundo elige el lugar exacto. El zoom manual se descarta al cambiar de escena.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Celular: elegir Construir | se ve el mapa entero, sin acercar a las construcciones propias |
| Primer toque cerca de una zona | la cámara se acerca a esa zona |
| Rueda hacia abajo | el mapa se aleja alrededor del puntero |
| Pellizco con dos dedos | el mapa se acerca alrededor del centro de los dedos |
| Arrastrar con un dedo | el mapa se mueve |

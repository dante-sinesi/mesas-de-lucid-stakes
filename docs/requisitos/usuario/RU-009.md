# RU-009: Construir

## Descripción

Las cuatro opciones se ven siempre con su costo; las que no se pueden quedan apagadas con lo que falta, y si no se puede ninguna el título dice «No puedes construir nada» y el botón es «Pasar».

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Mano [0,0,2,0,1] | las cuatro opciones apagadas y botón «Pasar» |
| Tocar la ciudad sin recursos | no abre nada y avisa lo que falta |

## Origen

Dante, en el diseño de las pantallas (`docs/fundacion_v2_pantallas.md`, decisiones D-001 a D-016).

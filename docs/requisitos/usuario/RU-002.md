# RU-002: Medidor de tiempo de turno

## Descripción

Una barra arriba de toda la pantalla muestra el tiempo del turno («Tu turno» o «Turno de X») en todos los turnos, también de bots, y queda gris cuando no hay tiempo que contar.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Turno de un bot | la barra baja durante 14 segundos |
| Tirada de dados | la barra queda gris sin texto |

## Origen

Dante, en el diseño de las pantallas (`docs/fundacion_v2_pantallas.md`, decisiones D-001 a D-016).

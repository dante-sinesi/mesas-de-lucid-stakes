# RU-004: Contador de piezas

## Descripción

El HUD muestra, con el icono de cada pieza, cuántas tiene el jugador y el máximo (caminos 2/15, pueblos 2/5, ciudades 0/4, caballeros 0/3).

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Un jugador con 2 pueblos | el contador muestra 2/5 junto al icono de pueblo |

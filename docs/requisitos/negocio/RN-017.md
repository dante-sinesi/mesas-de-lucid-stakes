# RN-017: Un pedido que no se puede cumplir no se abre

## Descripción

El servidor rechaza la entrega de un pedido que el jugador no puede cumplir, y el cliente no abre su ventana.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Mano [1,1,0,0,0] y pedido «3 tarjetas iguales» | la entrega se rechaza y la pantalla avisa «Necesitas 3 tarjetas iguales» |

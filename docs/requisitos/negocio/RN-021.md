# RN-021: Al agotarse el reloj el turno se pasa solo

## Descripción

Cuando se agota el reloj del turno, el turno se pasa solo; si había un descarte obligatorio sin hacer, se descartan al azar las tarjetas necesarias.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Un jugador con 8 tarjetas deja agotar el reloj | se descartan 2 al azar y el turno pasa |

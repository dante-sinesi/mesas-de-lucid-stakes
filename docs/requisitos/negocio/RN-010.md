# RN-010: Una acción por turno

## Descripción

En su turno, un jugador hace una sola acción: construir una pieza o entregar un pedido. Al hacerla el turno termina solo; si no quiere o no puede hacer nada, pasa. (Antes eran todas las acciones que alcanzaran; ver [[ADR-007]].)

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Tiene recursos para dos caminos y construye uno | el turno termina al construir |
| Entrega un pedido | el turno termina al entregar |
| No le alcanza para nada | pasa y el turno termina |

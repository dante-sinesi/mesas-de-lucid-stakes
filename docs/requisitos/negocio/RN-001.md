# RN-001: Sin dados de recursos ni oro

## Descripción

Fundación no tiene dados de recursos ni oro; los recursos son cinco: madera, ladrillo, lana, trigo y mineral.

## Ejemplos verificables

| Entrada | Resultado esperado |
|---|---|
| Se crea una partida | el estado no contiene oro ni dados de recursos; la mano tiene 5 cuentas |
